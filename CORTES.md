# Cortes para la música

Los tiempos de cada escena dependen de la configuración de cada video.
Para verlos, abre `npm run studio`: la línea de tiempo muestra cada escena.

Tiempos fijos de la plantilla (30 fps):

| Parte | Duración |
|---|---|
| Intro Aelika | 0:00 – 0:04.1 (el flujo empieza en 0:03.7) |
| Post de Instagram | 3 s |
| Perfil de Instagram | 4 s |
| Linktree | 3 s |
| Storefront de citas | 20 s |
| Add-ons | 1.1 s + 1 s por tarjeta + 3.7 s |
| Outro Aelika | 6.3 s |
