# Brief · Pulso Studio

- **Tipo:** demo comercial · **variante:** genérica de giro (fitness) · **Id:** `PulsoStudio` · **fecha:** 2026-11-19
- **Flujo:** clases (`classesStorefront`) · **duración:** 70.5 s

## Para qué
- Mandarla a cualquier estudio o gimnasio, y como base para versiones personalizadas
  (`npm run new -- pulso-studio <gimnasio> <Id> "Nombre"`).
- **Pulso Studio es una marca ficticia.** La narración no menciona el nombre del negocio: al personalizar, se reutiliza el mismo audio.

## Contenido
- Clases: Cycling, Funcional, Yoga Flow, Box Fit; coaches Ana, Diego, Sofía (de ambos géneros, etiqueta "Coach").
- Pago: clase suelta, paquetes de 5 y 10, mensualidad ilimitada; Apple Pay.
- Solo funciones que ya aparecían en Detona (asistente de WhatsApp, reserva en tiempo real, código por WhatsApp, paquetes, recordatorios, campañas, avisos al equipo, lealtad).
